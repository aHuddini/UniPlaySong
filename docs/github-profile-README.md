## 🎮 About

* I build extensions for [Playnite](https://playnite.link/) — the open-source game library manager
* Mostly audio, video, and artwork: making a library feel alive instead of like a spreadsheet
* Using `C#`, `WPF`, `NAudio`, `SDL2`, a bit of `Python`

Feel free to check out the projects below — a few of them talk to each other.

| | |
|---|---|
| **[UniPlaySong](https://github.com/aHuddini/UniPlaySong)** | Per-game music with live effects, a spectrum visualizer, radio mode, and Spotify |
| **[ControlUp](https://github.com/aHuddini/ControlUp)** | Detects your controller and switches Playnite to Fullscreen, hands-free |
| **[FullReel](https://github.com/aHuddini/FullReel)** | Trailers and gameplay videos for your library, without leaving Playnite |

| **[ImageRotater](https://github.com/aHuddini/ImageRotater)** | Rotates background and cover artwork so your library never looks the same twice |
| **[BeautyCons](https://github.com/aHuddini/BeautyCons)** | Custom icons to make your library yours |

## ☕ Support

All of this is free, MIT, and built in my own time — no ads, no telemetry, no paid tiers.

If an extension earned a place in your setup, [**a coffee on Ko-fi**](https://ko-fi.com/huddini)
or a [**GitHub sponsorship**](https://github.com/sponsors/aHuddini) keeps them coming — one-off or
monthly, both help. Happy to talk about feature work, theme integrations, or backing a specific
plugin.

Not in a position to give? Starring a repo, filing a good bug report, or telling another
Playnite user works just as well.
