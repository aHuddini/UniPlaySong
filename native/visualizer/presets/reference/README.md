# Visualizer reference presets

Not shipped. Material kept for future experiments.

- `test-presets/` - the MilkDrop variants that were stepped through live in Playnite (F8/F9) while the Jukebox
  Fountain was developed, including a `.tune` template and `!! Pixel check (1-1).milk` (a 1 px pattern that shows any
  rescale of the frame as moire). The F8/F9 code was removed; to try one again, point a style at it temporarily.
- The bench's own presets (Your tune #4 and #5, the T8 standard, the Showcase and Spectrum looks) live in
  `../../bench/fountain-bench.html`; `../../bench/standard-t8.json` freezes the T8 standard ("T8": the droplet style is
  inspired by Tekken 8's music jukebox visualizer).

The shipped look is **Your tune #6**: `../../bench/standard-tune6.json`, exported to
`UPS - Jukebox Fountain.vis` by `../../bench/tools/export_t8.mjs`.
